# Security

This repository contains instructions and local helper scripts. The helper scripts are designed to use the Python standard library and do not require secrets.

Before installing any third-party Grok plugin, review its contents. Grok plugins execute with the user's permissions. This SEO plugin does not ship hooks, MCP server configuration, or background executables.

Report security issues privately to the repository maintainer after publication rather than posting exploitable details in a public issue.
